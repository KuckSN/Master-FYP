# Master-FYP

Final Year Project focused on ship detection from satellite imagery.

## Project goals

- Build and compare ML-based ship detection pipelines
- Explore LLM-assisted vision and annotation workflows
- Organize datasets, experiments, and evaluation artifacts

## Repository structure

- `data/`: raw, processed, and annotation datasets
- `notebooks/`: exploratory analysis and experimentation
- `src/`: reusable project code for data, models, evaluation, and utilities
- `models/`: trained ML and LLM model artifacts
- `configs/`: configuration files for experiments and training
- `scripts/`: automation scripts for training and evaluation
- `tests/`: validation and regression checks
- `docs/`: project planning and design notes
